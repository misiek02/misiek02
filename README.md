## 🚀 Projects

### 🛩️ Multi-Object-Tracking

Master's thesis project on multi-object tracking of airborne objects (UAVs) in infrared video using deep learning. Implements a Tracking-by-Detection pipeline combining **YOLO26** and **RT-DETR** detectors with **ByteTrack**, **BoT-SORT**, and **StrongSORT** trackers, evaluated on the Anti-UAV dataset using HOTA, MOTA, and IDF1 metrics.

![](https://ziadoua.github.io/m3-Markdown-Badges/badges/Python/python1.svg)
![](https://ziadoua.github.io/m3-Markdown-Badges/badges/PyTorch/pytorch1.svg)

### 🤖 Scan-Matching-Methods

Engineering thesis project comparing point-cloud scan-matching algorithms — **ICP**, **TEASER++**, and **NDT** — for laser-scanner-based robot localization. Built and tested in a ROS 2 / Gazebo simulation environment using a TurtleBot3 robot equipped with 2D and 3D LiDAR sensors.
